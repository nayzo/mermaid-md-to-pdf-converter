# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-01-30

### Added
- Initial release
- Convert Markdown files to PDF
- Automatic Mermaid diagram rendering
- CLI tool with customizable options
- Node.js API for programmatic usage
- Support for multiple PDF formats (A4, A3, A5, Letter, Legal, Tabloid)
- Configurable Mermaid themes (default, neutral, dark, forest)
- Custom colors, fonts, and margins
- Professional typography with Google Fonts integration
- Syntax highlighting for code blocks
- Styled tables, blockquotes, and lists
- Automatic page break handling
- Example Markdown file with Mermaid diagrams

### Features
- **CLI Options**:
  - `--format` - PDF format selection
  - `--theme` - Mermaid theme selection
  - `--color` - Primary color customization
  - `--font` - Font family selection
  - `--font-size` - Font size customization
  - `--margin-*` - Individual margin control

- **Supported Markdown Features**:
  - Headers (H1-H6)
  - Text formatting (bold, italic, strikethrough)
  - Lists (ordered and unordered)
  - Tables
  - Code blocks with syntax highlighting
  - Blockquotes
  - Links
  - Images
  - Horizontal rules
  - Mermaid diagrams (all types)

- **PDF Features**:
  - Professional styling
  - Centered H1 titles
  - Syntax-highlighted code blocks
  - Alternating table row colors
  - Page break optimization
  - Print-friendly layout
